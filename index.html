Build Full-Stack.
At Lightning Speed.

Barq is a strictly-typed, full-stack programming language with Python-style syntax and PHP-level power. Write your backend, frontend, and database logic in a single, beautiful language.

Get Started Read the Docs

برق — Urdu for Lightning

HomeController.bq 
namespace App\Controllers

use App\Models\User
use Barq\Http\Request

class HomeController

    #[Public]
    #[View]
    karo index(Request request)
        users = User
            .where("active", true)
            .orderBy("name")
            .paginate(20)
        return view("home", #{ users: users })

    #[Public]
    #[Response]
    karo store(Request request)
        string name  = request.input("name")
        string email = request.input("email")
        user = new User(name, email)
        user.save()
        return response().redirect("/")

Why Barq

Everything you need.
Nothing you don't.

Barq ships with a complete standard library — no npm, no pip, no composer. One language for the full stack.

Sub-Millisecond Speed

runtime.bq
// First run: compile → cache .bqc Runtime.compile("app.bq") .cache(".bqc") // Subsequent runs: load bytecode Runtime.load("app.bqc") // ~0.4ms Runtime.execute()

Compiles to bytecode on first run. Cached .bqc files load in <0.5ms with no interpreter overhead.

Strictly Typed

user.bq
#[string] karo greet(string name) return "Hello, " + name // ✗ caught at compile time: greet(42) // TypeError: expected string, got int

The compiler catches type mismatches, null errors, and wrong returns before you run a single line.

True Full Stack

routes.bq
// HTTP → DB → Template, one file Route::get("/posts", "PostController@index") .middleware("auth") // Controller returns a view return view("posts.index", #{"posts": posts})

One language for routing, DB queries, templates, and reactive SPA components. No context switching.

Multi-Database

query.bq
// Same API — MySQL, PG, SQLite posts = Post .where("published", true) .with("author") .orderBy("created_at") .paginate(15)

MySQL, MariaDB, PostgreSQL, SQLite, MongoDB. Switch engines without rewriting a single query.

SPA & Reactive UI

counter.bq
component Counter int count = 0 template <button @click="count++"> Clicked {count} times </button>

Vue.js-style reactive components in pure Barq. No JavaScript framework — no npm, no webpack.

Zero Dependencies

stdlib.bq
use Barq\Http\Client use Barq\Crypto\Hash use Barq\Mail\Mailer use Barq\Queue\Job use Barq\Test\Assert // all built-in — zero install

HTTP, crypto, mail, queues, testing — all in the standard library. Start productive from line one.

Code Examples

Clean syntax.
Familiar patterns.

01

Expressive ORM

Chain query methods just like Laravel's Eloquent. Barq's ORM works identically across MySQL, PostgreSQL, and SQLite — no raw SQL required.

02

Declarative Routing

Map URLs to controllers in a single routes file. Group routes by prefix, apply middleware, and define RESTful resources with minimal code.

03

HTML-Native Templates

Barq templates use HTML-tag directives — <each>, <if>, {variable} — that feel natural to anyone who knows HTML.

// Fluent query builder — same API for all SQL engines
users = User
    .where("active", true)
    .where("age", ">", 18)
    .with("posts")
    .orderBy("name", "asc")
    .paginate(20)

// Create & save
user = new User()
user.name  = "Alice"
user.email = "alice@example.com"
user.save()

// Transactions
db.transaction(karo(): void
    db.table("accounts")
      .where("id", fromId)
      .decrement("balance", amount)
    db.table("accounts")
      .where("id", toId)
      .increment("balance", amount)
)
use App\Controllers\UserController
use App\Middleware\Auth

// Web routes — :id is a route parameter
Route.get("/", kr(): string => "<h1>Home</h1>")
Route.get("/users/:id", #[UserController, "show"]).whereNumber("id")
Route.resource("posts", PostController)

// API group with middleware
Route.alias("auth", Auth)
Route.group(#{"prefix": "api/v1", "middleware": "auth"}, karo(): void
    Route.get("/profile", #[ProfileController, "show"]).name("api.profile")
    Route.put("/profile", #[ProfileController, "update"])
)

Route.serve(#{"port": 8000})
<!-- views/users/index.bq -->
<if condition="users.length > 0">
    <ul class="user-list">
    <each item="user" in="users">
        <li class="card">
            <strong>{user.name}</strong>
            <span>{user.email}</span>
            <if condition="user.active">
                <span class="badge-green">Active</span>
            </if>
        </li>
    </each>
    </ul>
<else>
    <p class="empty">No users found.</p>
</if>
